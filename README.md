# Passenger Screen

This standalone static site loads the current Free-TV/IPTV USA playlist from GitHub and provides a YouTube video-link embed. It uses native browser playback, starts nothing automatically, and disables insecure HTTP stream URLs on the HTTPS site. It does not work around vehicle, browser, provider, regional, or legal playback restrictions.

The playlist is maintained by [Free-TV/IPTV](https://github.com/Free-TV/IPTV/blob/master/playlists/playlist_usa.m3u8). The website does not host or alter streams; availability and terms are set by upstream maintainers and the respective providers. GitHub Pages serves `index.html` from this repository root.
